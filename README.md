# MiniWorld Demo

An evolving English-learning game prototype combining a town-life story, reviewed learning activities and a learning-agent design.

[Project presentation, poster and video](https://miniworld-learning-prototype.gengmin2020.chatgpt.site/)

## Playable demo
The release package is for **Apple silicon Macs running macOS 12 or later**. [Download the complete Mac demo ZIP](https://github.com/G-arwen/MiniWorld-Demo/releases/download/demo-v0.40/MiniWorld_Mac_Prototype.zip) · [Release notes and checksum](https://github.com/G-arwen/MiniWorld-Demo/releases/tag/demo-v0.40)

Extract `MiniWorld_Mac_Prototype.zip`, then open `MiniWorld_Reviewer.app` in Finder. The app is not Apple-notarized; use the video and PDFs if your device restricts launch. Do not disable system protections.

This portable review edition is **offline**, with no API key or microphone capture. It is separate from the owner's online-planning development build. Quick exploration uses an isolated preset adult-review profile, not a child's record.

## Scope and contribution
The current first-episode demo is a working slice of the original eight-chapter product direction. It is not the complete game or evidence of measured learning gains.

Product direction, learning requirements, content review and play feedback are by the project owner. Codex assists implementation and technical checks. Artwork is AI-assisted and voices are synthesized. Applicable engine, font and voice-source notices remain in the application. The assets are not offered as a separately cleared commercial asset library.

Only public distribution materials belong here. Private applicant PDFs, account credentials and real child records are not included.
